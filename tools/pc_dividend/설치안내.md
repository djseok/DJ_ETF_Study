# PC 배당 수집 설치 (TIGER·RISE)

미래에셋(TIGER)과 KB(RISE)는 2026년 10~11월부터 해외 서버(GitHub·구글)의 접속을 막고 있습니다. 그래서 이 두 운용사의 분배금과 과세표준은 한국 IP 인 동진님 PC 에서 받아 시트에 기록합니다. 나머지 운용사는 지금처럼 GitHub 가 매일 처리합니다.

- 매일 09:00 에 실행됩니다. 그 시각에 PC 가 꺼져 있었으면 켜진 뒤 바로 실행됩니다.
- 이미 기록된 날짜는 건너뛰므로, 며칠 빠져도 다음 실행 때 채워집니다.
- 코드는 매번 저장소에서 최신 파일을 받아 씁니다. 고칠 일이 생겨도 PC 에서 따로 할 일은 없습니다.

## 1. 파이썬 설치 (한 번)
1. https://www.python.org/downloads/ 에서 최신 Python 3 을 받아 설치합니다. 첫 화면 아래의 **"Add python.exe to PATH"** 를 꼭 체크하세요.
2. 시작 메뉴에서 **PowerShell** 을 열고 아래 줄을 붙여 넣습니다.
   ```
   python -m pip install requests pandas lxml beautifulsoup4 urllib3
   ```

## 2. 실행 파일과 설정 파일 (한 번)
PowerShell 에 아래를 통째로 붙여 넣습니다.
```
$dir = "$env:USERPROFILE\dj_dividend"
New-Item -ItemType Directory -Force $dir | Out-Null
Invoke-WebRequest https://raw.githubusercontent.com/djseok/DJ_ETF_Study/main/tools/pc_dividend/run_dividend.bat -OutFile "$dir\run_dividend.bat"
Set-Content "$dir\config.bat" "set WEBHOOK_URL=여기에_웹앱_주소`r`nset WEBHOOK_TOKEN=여기에_토큰" -Encoding ascii
notepad "$dir\config.bat"
```
메모장이 열리면 두 값을 바꿔서 저장합니다. 값은 GitHub Secrets 에 넣은 것과 같습니다.
- **WEBHOOK_URL**: 마스터시트 Apps Script → 배포 → 배포 관리 → 웹 앱 URL (`https://script.google.com/macros/s/…/exec`)
- **WEBHOOK_TOKEN**: 마스터시트 Apps Script → 프로젝트 설정(톱니바퀴) → 스크립트 속성 → `WEBHOOK_TOKEN` 값

이 파일은 PC 에만 있고 저장소에는 올라가지 않습니다.

## 3. 매일 자동 실행 등록 (한 번)
PowerShell 에 붙여 넣습니다.
```
$dir = "$env:USERPROFILE\dj_dividend"
$a = New-ScheduledTaskAction -Execute "$dir\run_dividend.bat"
$t = New-ScheduledTaskTrigger -Daily -At 9:00am
$s = New-ScheduledTaskSettingsSet -StartWhenAvailable -ExecutionTimeLimit (New-TimeSpan -Minutes 30)
Register-ScheduledTask -TaskName "DJ_배당수집" -Action $a -Trigger $t -Settings $s -Force
Start-ScheduledTask -TaskName "DJ_배당수집"
```
마지막 줄이 바로 한 번 실행합니다. 1~2분 뒤 `notepad $dir\log.txt` 로 결과를 볼 수 있습니다. `end (exit 0)` 으로 끝나고 "✅ 전송 완료" 또는 "⏭️ 통과 (중복)" 줄이 보이면 정상입니다. `exit 1` 이면 위쪽 오류 줄을 캡처해 Claude 에게 보내 주세요.

## 끄기
```
Unregister-ScheduledTask -TaskName "DJ_배당수집" -Confirm:$false
```
